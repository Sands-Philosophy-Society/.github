# Sands Philosophy Society

**Version-controlled philosophical dialogue. The modern Socratic method.**

---

## What This Is

The Sands Philosophy Society is an experiment in collaborative philosophy using the tools of software development. Each repository contains a philosophical framework proposed by Harrison Sands (Sands Scientific Limited, New Zealand). Each framework is treated as a living document — open to critique, amendment, and extension by anyone willing to engage seriously with the ideas.

We use Git's version control architecture to do what Plato's dialogues could not: preserve every draft, every objection, every amendment, every branch of argument, and every resolution. The commit history of an idea becomes philosophy itself.

## How It Works

1. **Read** the canonical version of any framework (the main branch README in each repository).
2. **Discuss** by opening an Issue. Issues are the Socratic questions. Ask anything. Challenge anything. Disagree with anything.
3. **Propose amendments** by forking the repository, making your changes, and submitting a Pull Request. Pull Requests are formal philosophical arguments for changing the canonical text.
4. **The community discusses** the Pull Request. If the argument is sound, the amendment is merged into the canonical version.
5. **Everything is preserved.** Rejected arguments remain visible in closed Pull Requests. The full history of every idea's development is permanently recorded.

See .github/HOW_TO_CONTRIBUTE.md for detailed guidelines.

## Why Git for Philosophy

In the ancient Greek tradition, philosophy was dialogue. Socrates and his interlocutors argued, refined, and sometimes reversed their positions through conversation. But we only have Plato's edited final versions. The drafts, the deleted scenes, the moments of confusion and reversal — all lost.

Git preserves what Plato could not. Every commit is a moment of thought. Every branch is an alternative path of reasoning. Every merge is a resolution. Every rejected Pull Request is a considered-and-dismissed argument that remains available for future thinkers to revisit.

Philosophy is not a finished product. It is an ongoing process. Git is the first tool in human history that can faithfully represent that process.
